# MERIDIAN — Construction Group

> Premium construction & development since 1987. Building tomorrow's landmarks across Europe.

---

## About

**Meridian Construction Group** is a Berlin-based premium construction firm specializing in commercial towers, residential masterpieces, industrial complexes, and heritage restorations. Founded in 1987, Meridian has delivered over 240 projects across Europe with a total value exceeding €1.2 billion.

This website represents the digital presence of Meridian — designed and built to reflect the same precision, craft, and enduring quality that defines every structure we create.

---

## Design

- **Brand:** Warm copper on deep charcoal — structural, grounded, premium
- **Typography:** High-contrast heading hierarchy with tight tracking and generous body spacing
- **Layout:** Asymmetric grids, purposeful whitespace, geometric structural elements
- **Motion:** Scroll-triggered reveals, subtle parallax, counter animations, tilt micro-interactions
- **Icons:** Handcrafted SVG iconography — no external dependencies

---

## Technical

- Pure **HTML5**, **CSS3**, and **Vanilla JavaScript** — zero frameworks, zero dependencies
- Fully **responsive** across all breakpoints
- Custom cursor with magnetic hover states
- Intersection Observer–powered scroll animations
- CSS custom properties for consistent theming
- Optimized for **GitHub Pages** with relative paths
- No external assets, fonts, or scripts
